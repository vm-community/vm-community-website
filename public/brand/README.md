# Brand assets placeholder

The official VibeMind / Vibe Mind AI Solutions logo is **not** included in this repository.

`src/components/vm/Logo.tsx` renders an original text wordmark ("VibeMind Community") with a small
original network-nodes glyph. **Replace `Logo.tsx` with the official logo asset** when it is supplied,
and drop the raster/SVG files in this folder (`public/brand/`).

Nothing in this folder imitates the parent brand's logo.
