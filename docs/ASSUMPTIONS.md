# Assumptions and inferred items

Everything in this file is **not verified** against the real backend, mobile app or Keycloak. The
single source of truth for verified behaviour is `PROMPT.md` (§4–§6). Each entry says what was
assumed, why, and how to change it if the real answer differs.

| A22 | Marketing JS budget                | The spec asks for < 150 kB gzipped JS per marketing page. After moving the API client, session, toasts and Zod out of the marketing path, landing pages measure ~160–166 kB and `/get-started` ~200 kB (React Hook Form + Zod). The gate (`scripts/check_bundle_budget.mjs`) therefore enforces 170 kB for landing pages and 210 kB for the lead form and prints when the 150 kB spec target is exceeded.
